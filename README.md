# Suivi des paiements

Application web installable (hors ligne) pour suivre les paiements d'un cabinet : encaissements, dépôts en banque, relances, seuils.

Ce dépôt ne contient que le code. Les données restent sur l'appareil de l'utilisatrice, chiffrées par son mot de passe (AES-GCM 256 bits) ; rien n'est envoyé sur Internet.

Fichiers construits depuis les sources privées (`python3 outils/build.py`) : ne pas les modifier ici.
